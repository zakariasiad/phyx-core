# Security Policy

## Supported Versions

PHYX is currently in early development. Security support applies to the latest version available on the default branch unless a release explicitly states otherwise.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in public issues.

Report vulnerabilities privately to the project maintainers with:

- A clear description of the issue
- Affected component or version
- Steps to reproduce
- Potential impact
- Any suggested mitigation

The maintainers will review the report and coordinate disclosure when appropriate.

## Robotics Safety

Security reports involving physical hardware, remote execution, unsafe actuation, authentication, or sensor/control integrity should clearly describe the possible physical impact.

PHYX should never be deployed to safety-critical environments without independent validation and appropriate hardware-level safety mechanisms.
