# PHYX Governance

PHYX is an open-source project. Governance is designed to encourage transparent technical discussion, responsible maintenance, and broad community participation.

## Maintainers

Maintainers are responsible for:

- Reviewing contributions
- Protecting project quality and security
- Managing releases
- Maintaining project infrastructure
- Resolving technical disputes when consensus cannot be reached

## Decision Making

Small, reversible changes can be decided through normal pull request review.

Significant architectural changes should be discussed publicly through GitHub Issues or Discussions before implementation.

Changes affecting public APIs, core architecture, security, licensing, or project governance require maintainer review.

## Community Contributions

Contributors are encouraged to propose:

- Features
- Research directions
- Hardware integrations
- Simulation environments
- Documentation
- Benchmarks
- Performance improvements

## Long-Term Direction

The project aims to remain open, modular, research-friendly, and commercially usable. The open-source core should remain useful independently of any future commercial services built around PHYX.
